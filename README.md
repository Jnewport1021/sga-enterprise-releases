# SGA Enterprise Releases

Official signed SGA Enterprise application releases and public update metadata.

## Installation

When an approved release is available, open the latest release and download the Windows installer. Only install assets published by **Jnewport1021** in this repository.

[Open the latest approved release](https://github.com/Jnewport1021/sga-enterprise-releases/releases/latest)

Every installer is accompanied by signed release metadata and a SHA-256 checksum. SGA Enterprise verifies both before an automatic update is activated.

## Security boundary

This public repository must contain only:

- signed application installers;
- signed release metadata and checksums;
- public installation instructions.

It must never contain source code, private signing keys, passwords, workspace setup addresses, printer or access-control configuration, employee information, activity history, or operational data.

## Current status

The GitHub-only 8.0.0 installation and update path is being prepared and verified. Existing SGA computers must continue using the current approved update path until the OneDrive-unavailable safety test passes.
